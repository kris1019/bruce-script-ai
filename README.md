- Searchable profile library
- Live Ollama streaming
- Game-style polished Tkinter GUI

```bat
ollama pull qwen2.5-coder:7b
git clone https://github.com/kris1019/bruce-script-ai.git
cd bruce-script-ai
run.bat
```
